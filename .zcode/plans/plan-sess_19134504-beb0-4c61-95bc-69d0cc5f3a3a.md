# 设备列表首页 + 多设备管理 + 重命名

## 设计方向（frontend-design）

保持现有"仪器读数"深色美学：`void #080B12` 背景、mono 眉题/读数（Menlo）、hairline 分隔。设备列表页做成"已配对主机"控制台：眉题 `PAIRED HOSTS`，每项显示设备名（可编辑标识）+ mono 脱敏 URL 读数（`redactRemoteUrl`）+ 上次连接时间；空态给出扫码引导。删除用 danger、连接态用 signal，语义遵守 theme 约定。

## 改动

### 1. `src/lib/remote-url.ts`
- 新增纯函数 `extractDeviceName(url): string | null`（从 URL query 取 `name` 参数）。

### 2. `src/lib/secure-remote-store.ts` — 多设备存储
- 新类型 `RemoteDevice = { id, url, name, createdAt, lastConnectedAt }`。
- 新 STORAGE_KEY `zcode.remote.devices.v1`；保留旧 key `zcode.remote.url.v1` 迁移：首次启动读到旧单 URL → 转为一条设备记录（默认名取 `extractDeviceName` 或 `ZCODE Remote`）。
- API：`loadDevices()`、`saveDevices(list)`（内部使用）；`upsertDevice(url): Promise<RemoteDevice>`（按 normalize 后 URL 去重，存在则更新 lastConnectedAt）、`renameDevice(id, name)`、`deleteDevice(id)`、`findDeviceByUrl(url)`。

### 3. 新组件 `src/components/DeviceListScreen.tsx`（替代 SetupScreen 成为首页）
- Props：`{ devices, activeDeviceId, onConnectDevice(device), onRenameDevice(id, name), onDeleteDevice(id), onScanRequest }`。
- UI：SafeAreaView + FlatList；眉题/标题区；每项：设备名（text 字体）、mono 脱敏 URL、时间；右侧 `⋯` 按钮（testID `device-menu-<id>`）打开操作弹层（重命名 / 删除）；重命名为居中 Modal 对话框（TextInput + 确认/取消，testID `rename-input` / `rename-confirm`）；删除需确认（danger 文案）。
- 添加区：底部「添加设备」卡片：扫码按钮（复用 `open-scanner-button`）+ 粘贴 URL TextInput（`remote-url-input`）+ 连接按钮（`connect-button`），逻辑沿用 SetupScreen 现有校验/错误展示。
- testID：`device-item-<id>`、`device-menu-<id>`、`rename-input`、`rename-confirm`、`delete-confirm`、`add-device-card`。

### 4. `App.tsx`
- 状态改为 `devices: RemoteDevice[]` + `activeDevice: RemoteDevice | null`；启动 `loadDevices()`（含迁移），不自动连接 → 渲染 DeviceListScreen。
- `connect(url)`：`upsertDevice` 后刷新列表并进入 RemoteShell；深链/扫码复用同一路径。
- `onRenameDevice` / `onDeleteDevice` 直接调 store 并刷新；删除当前 activeDevice 则回列表。
- RemoteShell 的 `onSetup` 语义改为"返回设备列表"（`setActiveDevice(null)`），**不再 clear 存储**。

### 5. `RemoteShell.tsx`
- header 新增"设备"返回入口（testID `back-to-devices`），点击回调 `onExit`（原 `onSetup` 改名）。

### 6. SetupScreen 处理
- SetupScreen 逻辑并入 DeviceListScreen 后删除该组件及其测试，避免双入口（AGENTS.md 安全说明文案迁移到列表页）。

### 7. 测试
- `secure-remote-store.test.ts`：数组 CRUD、按 URL 去重、旧 key 迁移。
- `remote-url.test.ts`：`extractDeviceName`。
- 新 `DeviceListScreen.test.tsx`：渲染列表、重命名对话框流程、删除确认、添加设备校验。
- `App.test.tsx`：更新 mock（loadDevices 等），断言启动进列表、连接后进 RemoteShell、返回列表不清数据。
- `RemoteShell.test.tsx`：onExit 回调与返回按钮。
